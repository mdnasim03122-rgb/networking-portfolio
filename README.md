# MD. Nasim Hosen — Networking Portfolio

Responsive React + Vite portfolio in Deep Navy `#080D18`, Royal Blue `#2563EB`, and Lime `#B9F227`.

## Features
- Animated network globe with rotating orbits, connected nodes and moving signal lines
- Uses your supplied portrait (`public/profile.jpg`)
- Home, About Me, Skills, Experience, Projects and Contact sections
- Responsive desktop/tablet/mobile layout and reduced-motion accessibility support
- Contact links and editable profile details

## Run locally
1. Install Node.js LTS if it is not already installed.
2. Extract the ZIP and open the project folder in a terminal.
3. Run `npm install` (Windows PowerShell can use `npm.cmd install`).
4. Run `npm run dev` (Windows PowerShell can use `npm.cmd run dev`).
5. Open the local URL Vite displays, normally `http://localhost:5173/`.

## Personal information
Profile details are at the top of `src/App.jsx` in the `P` object. Check your LinkedIn link before publishing; it currently uses the general LinkedIn homepage because a personal profile URL was not provided.

## Build
Run `npm run build`; the production files are written to `dist/`.
